간단 메모장 개인정보처리방침

시행일: 2026년 11월 17일

간단 메모장(이하 "이 확장 프로그램")은 사용자의 개인정보를 수집하지 않습니다. 이 문서는 이 확장 프로그램이 데이터를 어떻게 다루는지 설명합니다.

1. 저장하는 데이터

이 확장 프로그램은 메모장 기능을 위해 다음 정보만 사용자의 기기에 저장합니다.

  • 사용자가 직접 작성한 메모의 본문
  • 각 메모를 만든 시각과 마지막으로 수정한 시각
  • 메모를 구분하기 위한 내부 식별자와 마지막으로 열어 둔 메모의 식별자

2. 저장 위치와 전송 여부

위 데이터는 사용 중인 컴퓨터의 Chrome 브라우저 안(확장 프로그램 전용 로컬 저장소)에만 보관됩니다. 기기 간 동기화 기능을 사용하지 않으며, 개발자의 서버나 Google을 포함한 어떤 외부 서버로도 전송하지 않습니다.

3. 수집하지 않는 정보

이 확장 프로그램은 이름, 이메일, 위치, 방문 기록, 방문한 웹사이트의 내용 등 어떤 개인정보나 사용 기록도 수집하지 않습니다. 쿠키, 광고, 분석 도구, 외부 서비스도 사용하지 않습니다.

4. 제3자 제공

데이터를 수집하지 않으므로 제3자에게 판매하거나 제공하는 데이터도 없습니다.

5. 보관 기간과 삭제

메모는 사용자가 삭제할 때까지 기기에 남아 있습니다. 메모 화면의 "삭제" 버튼으로 개별 메모를 지울 수 있고, 확장 프로그램을 제거하면 저장된 메모가 모두 함께 삭제됩니다. 필요한 메모는 "내보내기" 버튼으로 텍스트 파일로 백업할 수 있습니다.

6. 방침의 변경

데이터 처리 방식이 바뀌면 이 페이지를 갱신하고 시행일을 고칩니다. 새로운 데이터를 수집하게 되는 경우에는 Chrome 웹 스토어 등록 정보와 확장 프로그램 업데이트 설명에도 함께 안내합니다.

Privacy Policy — 간단 메모장 (Simple Memo)

Effective date: November 17, 2026

This extension does not collect any personal data.

What is stored

Only the notes you write (their text, created and last-modified times, and an internal ID) and which note was last open. This is stored in the extension's local storage inside your Chrome browser on your device.

What is transmitted

Nothing. Notes are never synced or sent to the developer, to Google, or to any other server. The extension makes no network requests and uses no cookies, ads, analytics, or third-party services. It does not read the websites you visit.

Sharing

No data is collected, so no data is sold or shared with third parties.

Retention and deletion

Notes stay on your device until you delete them with the Delete button or remove the extension, which erases all stored notes. You can back up a note as a .txt file with the Export button.

Changes

If data practices change, this page and its effective date will be updated, and the change will be noted in the Chrome Web Store listing.
